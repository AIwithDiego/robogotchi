# Asset provenance

- Robot forms, expressions, rust overlays, wear marks, favicon and icons: original inline SVG authored for this project with Codex; no stock artwork, actor likeness or film assets.
- Interface: original CSS. Six room backgrounds generated with Higgsfield GPT Image 2.5 on 15 September 2026, one generation each. Original PNGs were inspected and encoded as JPEG at quality 85 for local delivery. Full prompts and the model used are recorded in `room-provenance.json`. Tiny shelf ornaments in the generated rooms are part of the background, separate from the live robot.
- Arcade playfields, block geometry and functional pixel sprites are original Canvas 2D drawings. Robot customization extends the original SVG; activity props and cosmetic accessories are original. Room rewards use platform emoji glyphs.
- Sounds: original short sine-wave tones synthesized locally through Web Audio, after sound is enabled. No sound recordings or external audio files.
- Typography: DM Sans and Space Grotesk, both distributed under the SIL Open Font License. The Latin variable files are self-hosted in `public/fonts/` with their licences, so no visitor request goes to a third-party font service. A system sans-serif fallback remains. Font source pages: https://fonts.google.com/specimen/DM+Sans and https://fonts.google.com/specimen/Space+Grotesk.
- React/Vite starter artwork is not used in the finished game.
